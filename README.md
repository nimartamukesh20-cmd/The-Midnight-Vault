# The-Midnight-Vault

## Overview
The Midnight Vault is a PHP-based escape room game developed for CSC 4370 - Web Programming at Georgia State University.

Players create an account, log in, solve three escape-room challenges, earn or lose points based of their performance, and view their final scores on a leaderboard.

## Gameplay 
1. Register a new account and log in.
2. Start with **1000 points**.
3. Complete Room 1.
4. Complete Room 2.
5. Complete room 3.
6. View your final score and escape time.
7. Check the leaderboard. 

### Scoring
- Starting score: **1000**
- Wrong Answer: **-50 points**
- Hint: **-100 points**
- Maximum hints: **3 per room**
